# Essential ASD-STE100 controls

This is a compact paraphrase of the essential database. Use the rule IDs for traceability. Use the official ASD-STE100 Issue 9 document and dictionary for authoritative wording.

| Rule IDs | Control |
| --- | --- |
| 1.1–1.4 | Use approved words with their approved meaning, part of speech, and forms. |
| 1.5–1.11 | Use necessary technical nouns; keep them short, clear, field-approved, defined when unfamiliar, and stable for one item. |
| 1.12–1.13 | Use necessary technical verbs; do not turn technical verbs into nouns. |
| 1.14 | Use one spelling variety consistently unless an official directive requires another. |
| 2.1–2.2 | Limit multi-word noun density; for a longer technical noun, write it in full, then make it clear with a short name or hyphens. |
| 3.1–3.5 | Use permitted verb forms; avoid complex auxiliaries and progressive “-ing” forms. |
| 3.6–3.7 | Use active voice and direct verbs; passive descriptive text is limited to cases where the agent is unknown. |
| 4.1–4.5 | Write short complete sentences; use explicit connectors, vertical lists, articles, and demonstratives. |
| 5.1–5.5 | Procedures: maximum 20 words per sentence, one instruction per sentence, imperative form, condition first, notes contain information only. |
| 6.1–6.6 | Descriptions: general to specific, stable key terms, maximum 25 words per sentence, one topic per paragraph, maximum six sentences per paragraph. |
| 7.1–7.3 | Safety: identify risk level, start with command or condition, and state hazard or possible result. |
| 8.1–8.7 | Do not use semicolons; use hyphens for directly related words; apply the standard's word-count conventions. |
| 9.1–9.4 | Rewrite when substitution fails; use words correctly; avoid making phrasal verbs; keep wording consistent. |
| GR-1–GR-8 | Review “that,” “with,” pronouns, “this,” false friends, Latin abbreviations, inclusive language, and possessive clarity. |

## Essential preservation rule

Reject any rewrite that removes a condition, qualification, actor, value, identifier, technical distinction, safety consequence, or required action order.
